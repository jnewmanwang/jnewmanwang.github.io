# jenny.github.io
Personal website. Layout adapted from a friend's Skeleton-CSS template.

## Customization checklist
Search `index.html` for `TODO` — each marks something to change.

- [ ] Name (title tag, header), job title/department/institution
- [ ] Photo: add `images/photo.jpg`
- [ ] Profile links (Scholar, LinkedIn, GitHub) and CV
- [ ] Email (in **two** places: the button and `copyEmail()` at the bottom)
- [ ] About paragraphs
- [ ] Papers: one `<ul>` each; link to a URL, or host a PDF in `papers/`
- [ ] Software / Teaching sections (edit or delete)
- [ ] Favicon (optional)

Styling lives in `css/custom.css` (layout, spacing) and `dist/css/skeleton.css` (base theme, fonts, colors).
